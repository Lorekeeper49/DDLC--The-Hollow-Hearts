If you want to add translations to this mod, follow these instructions:

1. Open the Ren'Py launcher making sure it is the same version as the mod's version, you can check in the VERSION file.
2. Click on the mod within the launcher and click "Generate Translations".  If it's not there, you'll need to change the projects directory in the preferences
3. Input the name and click "Generate Translations"
4. Once the translations have been generated, create a text document (.txt file) in the "tl/[language name]" folder called "display.txt" and put the language display name in there

If you followed these steps correctly, you should see the new language option on in the options and you can begin translating the mod.

ALL TRANSLATIONS SHOULD FOLLOW THE POLICY BELOW (I can't stop you if they don't, but this is probably the best way to follow them):

- Besides dialogue, all text sizes and english text should stay the same, the only thing that should be changed with the screen translations are the Japanese Kanji.
- The name used for the player, "CONTROLLER", should not be translated and kept as either English or a phonetic spelling for the language.
    - Similar named items that also have this capitalization should follow the same rules.
- If a certain text does not appear in the translation options, DO NOT TRANSLATE IT, there's a small chance it may be used for certain functionality.
- While the official Japanese translation uses a lot of the same text, it should be viewed as a reference for you to figure out the transaltions for your language.
    - Don't worry about if you can't read Japanese, it should be pretty simple to understand either way.
